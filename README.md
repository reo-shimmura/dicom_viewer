# DICOM ビューワ

頭部CT(DICOM)を読み込み、Axial / Coronal / Sagittal の3断面で閲覧できるビューワです。
Python + pydicom + numpy + PySide6 で実装しています。

## 課題の必須4処理と実装対応

| # | 処理 | 実装 (`dicom_viewer.py`) |
|---|---|---|
| 1 | フォルダ内のファイルを読み込み、シリーズごとに並べる | `read_folder()` : DICOM 以外を無視し、SeriesInstanceUID で分類 |
| 2 | スライスを位置の順に並べる | `build_series()` : Image Position (Patient) を法線ベクトルへ射影した位置でソート (InstanceNumber・ファイル名には依存しない) |
| 3 | 画素値をCT値に換算する | `build_series()` : `HU = 画素値 × RescaleSlope + RescaleIntercept` |
| 4 | CT値を表示の明るさに変換する | `State.to_display()` : ウィンドウ幅/レベルによる 0–255 への線形変換 |

## 機能

- **MPR**: Axial・Coronal・Sagittal の3面表示。十字線で連動し、画素間隔とスライス間隔から縦横比を補正
- **ウィンドウ調整**: 右ドラッグ、数値入力、プリセット (DICOM既定・脳・硬膜下・軟部組織・骨・肺)
- **計測**: 距離 (mm)、楕円ROI (Mean / SD / Min / Max / 面積)。PixelSpacing を使用
- **メタデータ活用**: 撮影条件・スライス位置・向きラベル (IOPから算出)・スケールバーを画像に重畳表示、カーソル位置の HU と患者座標をステータスバーに表示
- **タグ一覧**: 全 DICOM タグを検索付きで表示 (シーケンス・プライベートタグ対応、スライスに連動)
- **角度計測**: 3点指定 (画素間隔補正済み)
- **スラブ投影**: MIP / MinIP / 平均 (厚み mm 指定、全断面対応)
- **CT値ヒストグラム**: 現在スライスの分布と窓範囲を表示し、ドラッグで窓を指定
- **シネ再生**・矢印キーによるスライス送り、ホバー位置の CT値から組織の目安を表示
- ズーム・パン、白黒反転、複数シリーズの切替、画面のPNG保存
- 患者名・ID・生年月日は既定で非表示 (`P` キーで切替)

## 実行方法

```
pip install -r requirements.txt
python dicom_viewer.py                  # 同階層の DICOM/DICOM を自動で読み込む
python dicom_viewer.py <DICOMフォルダ>    # フォルダ指定 (起動後は Ctrl+O でも可)
```

動作確認: Python 3.12 / Windows 11

## 操作

| 操作 | 内容 |
|---|---|
| ホイール | スライス送り (Shift で5枚ずつ) |
| Ctrl+ホイール | ズーム (カーソル位置基準) |
| 右ドラッグ | ウィンドウ調整 (横=幅 W / 縦=レベル L) |
| 中ドラッグ | パン |
| 左クリック/ドラッグ | 選択中ツールの動作 |
| C / W / H / D / E / A | ツール切替: 位置(十字線) / 窓 / パン / 距離計測 / 楕円ROI / 角度計測 (3点、2点目が頂点、Escで取消) |
| 1〜6 | ウィンドウプリセット |
| I / X / R | 白黒反転 / 十字線表示 / ズーム解除 |
| P | 患者情報の表示切替 |
| T | DICOMタグ一覧 |
| L | Axialのみ / MPR 3面 の切替 |
| M | 投影切替: 通常 / MIP / MinIP / 平均 (厚みはツールバー) |
| Space | Axial のシネ再生 (fps はツールバー) |
| 矢印 / PageUp・PageDown / Home・End | スライス送り (1枚 / 10枚 / 先頭・末尾。最後にマウスを乗せたビューが対象) |
| ヒストグラム上でドラッグ | ウィンドウ範囲を指定 |
| Del / Ctrl+Del | 現スライスの計測消去 / 全消去 |
| Ctrl+O / Ctrl+S | フォルダを開く / 画面をPNG保存 |

## テスト

```
python -m unittest discover -s tests
```

位置ソート・HU換算・ウィンドウ処理・角度/ROI計測・スラブ投影などを合成データで検証します。

## データについて

DICOM データ (`DICOM/`) は患者情報を含むため、リポジトリには含めていません (`.gitignore` で除外)。
使用データは頭部CT 254枚 (512×512、0.469 mm/px、スライス間隔 0.5 mm、1シリーズ) です。
